# Pacman

Игра Pac-Man на C++ — учебный проект курса по инженерному C++. Логика вынесена
в статическую библиотеку `PacmanLib`; исполняемый файл и тесты линкуют одну и
ту же библиотеку, поэтому тест вызывает тот же код, который работает в игре.
Настройки окна читаются из `config.json` при запуске.

Сайт отвечает на вопросы «почему так устроено» и «как здесь работать». Как
собрать и запустить в три команды — в `README.md` репозитория.

## Быстрый старт

```powershell
python automation/generate_project_files.py
python automation/build_debug.py
.\build\bin\Debug\Pacman.exe
```

Запускать из корня проекта: `config.json` читается из текущего каталога, а не
из каталога с исполняемым файлом.
